BCA 2nd Year Subjects & Syllabus

1. Data Communication and Computer Network (Core-4)

Modules: Network Topologies, Transmission Media, OSI & TCP/IP Reference Models, Switching & Routing.

2. Database Management Systems Using PL/SQL (Core-5)

Modules: ER Modeling, Relational Algebra, Normalization (1NF, 2NF, 3NF), SQL Queries, PL/SQL Cursors & Triggers.

3. Computer Graphics (DSE-1(A))

Modules: Raster/Vector Displays, Scan Conversion Algorithms (Line, Circle, Ellipse), 2D/3D Transformations, Animation.

4. Python Programming (DSE-2(A))

Modules: Python Basics, Control Structures, Data Structures, File Handling, OOPs, Database Connectivity.

5. Optimization Technique (M-3)

Modules: Operations Research, Linear Programming Problem (LPP), Simplex Method, Transportation & Assignment Problems.

6. Artificial Intelligence (M-4)

Modules: Indian Knowledge System, Intelligent Agents, Search Algorithms (BFS, DFS, A*), Knowledge Representation, Expert Systems.

7. Web Designing (MD-2)

Modules: HTML5, CSS3, JavaScript Basics, Responsive Design, CSS Flexbox/Grid, Bootstrap Framework.

8. E-Commerce (SEC)

Modules: E-Commerce Models (B2B, B2C), Electronic Payment Systems, Web Security, Digital Marketing, Legal & Ethical Issues.
