1. Data Communication and Computer Network (Core-4)

Module I: Oral communication systems (Shruti, Smriti), Messenger systems (Doot Pranali), Panini's grammar (Ashtadhyayi), Vedic chanting methods.

Module II: Network goals, structure, services, centralized/distributed models, and Topologies (Bus, Star, Ring, Tree, Hybrid).

Module III: Transmission media (UTP, STP, Coaxial, Fiberoptics), communication satellites, analog/digital transmission, and switching techniques.

Module IV: LAN & WAN overview, media, topology, speed, distance, cost, and IEEE standards.

Module V & VI: OSI Reference Model (7 layers), Network Layer routing, gateways, bridges, routers, and TCP/IP model.

2. Database Management Systems Using PL/SQL (Core-5)

Module I: Introduction to DBMS, Database System Architecture, Data Independence, ER Model concepts, Entity sets, Attributes, Keys.

Module II: Relational Model, Relational Algebra, Relational Calculus, Integrity Constraints.

Module III: Database Design & Normalization: Functional Dependencies, 1NF, 2NF, 3NF, BCNF.

Module IV: Structured Query Language (SQL): DDL, DML, DCL commands, Joins, Subqueries, Views, Indexes.

Module V: PL/SQL: Control structures, Cursors, Stored Procedures, Functions, and Triggers.

3. Computer Graphics (DSE-1(A))

Module I & II: Historical Background, contributions of Indian scientists (Pingala, Narasimha Raghavan, etc.), Interactive and Passive Graphics.

Module III: Graphic Systems (CRT, Random Scan vs Raster Scan, Flat Panel Displays) and Input-Output Devices.

Module IV: Scan Conversion (DDA line algorithm, Bresenham's circle algorithm), filled area primitives, 2D transformations, and animation.

Module V: 3D Computer Graphics, 3D transformations, and hidden surface removal algorithms (Z-Buffer, Painter's algorithm).

4. Python Programming (DSE-2(A))

Module I: Introduction to Python, features, variables, data types, operators, and expression evaluation.

Module II: Control structures (if-else, loops), functions, scope of variables, modules, and packages.

Module III: Data Structures: Lists, Tuples, Dictionaries, Sets, and operations on them.

Module IV: File Handling (read/write text and binary files), Exception Handling (try-except-finally).

Module V: Object-Oriented Programming in Python (Classes, Objects, Inheritance, Polymorphism) and Database Connectivity.

5. Optimization Technique (M-3)

Module I: Introduction to Operations Research and Optimization Techniques.

Module II: Linear Programming Problem (LPP): Mathematical formulation, Graphical method, Simplex method.

Module III: Transportation Problems: Initial Basic Feasible Solution (North-West Corner, Least Cost, Vogel's Approximation) and Optimality test.

Module IV: Assignment Problems: Hungarian method for solving assignment problems.

Module V: Network Scheduling: CPM (Critical Path Method) and PERT (Program Evaluation and Review Technique).

6. Artificial Intelligence (M-4)

Module I: Indian Knowledge System (Panini's Ashtadhyayi, Pingala's binary concepts, Nyaya philosophy).

Module II: Introduction to AI, intelligent agents, rationalism, environment types, agent architectures, and knowledge-based agents.

Module III: Uninformed and Informed Search techniques (BFS, DFS, Best-first, A*, AO*, Minimax, Alpha-Beta pruning, Genetic algorithms).

Module IV: Knowledge representation using propositional/predicate logic, planning (STRIPS), and probabilistic reasoning.

Module V: Applications in Machine Learning, Computer Vision, Robotics, NLP, Deep Neural Networks, and Expert Systems.

7. Web Designing (MD-2)

Module I: Introduction to Web Design, Web Standards, HTML5 structure, semantic tags, tables, and lists.

Module II: CSS3 Styling: Selectors, colors, fonts, box model, Flexbox, and CSS Grid layout.

Module III: Responsive Web Design: Media queries, mobile-first design, and frameworks (Bootstrap basics).

Module IV: JavaScript Basics: Variables, data types, functions, DOM manipulation, and event handling.

Module V: Client-side form validation, hosting basics, and deploying web pages.

8. E-Commerce (SEC)

Module I: Introduction to E-Commerce, Electronic Commerce Framework, Anatomy of E-Commerce applications.

Module II: E-Commerce Business Models: B2B, B2C, C2C, C2B, and E-governance models.

Module III: Electronic Payment Systems: Credit/Debit cards, E-wallets, UPI, Smart cards, and Payment Gateways security.

Module IV: E-Security: Threats, encryption, digital signatures, SSL, firewalls, and security protocols.

Module V: Digital Marketing, SEO basics, and Legal/Ethical aspects of E-Commerce.
